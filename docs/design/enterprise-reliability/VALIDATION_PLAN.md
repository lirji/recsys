# 五目标验证与恢复演练计划

状态：计划，**以下业务测试尚未在本轮执行**。本轮仅文档检查，结果见 [REVIEW](REVIEW.md)。基线风险见 [评估](../../12-企业级搜推广评估.md)，步骤 ID 见 [PLAN](PLAN.md)。

## 验收口径

每次验证记录代码 revision、契约/测量政策/金额规则版本、环境和所有数据源、输入种子、执行命令、实际执行/跳过数量、事件 ID 与账本/队列/水位断言、耗时、结论及未验证项。测试数据写入隔离数据库，通过真实接口读取；不在页面硬编码正式数据。

“事件不漏”从服务端权威数据库提交并回复 accepted 开始。同步提交成功但客户端没收到响应属于结果未知，必须同键恢复；数据库整站灾难恢复由单独的备份 RPO/RTO 与演练覆盖。不得以一次正常 HTTP 200、Kafka send 成功或进程健康代替业务闭环。

## 可观测与指标解释

| 类别 | 最少保留的指标/证据 | 不得混淆 |
|---|---|---|
| 曝光 | 候选、资格签发、合格回执、重复/拒绝/过期、等待确认；policyVersion 与来源 | 签发并不证明响应收到；无回执不等于确定未展示 |
| 资金 | limit/held/charged/available、释放/冲正、未决预占年龄、对账差额 | 竞价价格不是实扣；账务快照应带版本/asOf |
| 事件 | 未发数/最老年龄、重试/隔离、Inbox/投影水位、重放结果 | broker ACK 不代表消费业务完成 |
| 恢复 | checkpoint、任务进度、备份可恢复点、重建总数/差额、实际恢复耗时 | 备份成功不代表恢复达标 |
| 效果 | accepted 分母、合法去重点击、成熟转化、实际模型、样本量与拒绝原因 | 合成结果不是线上提升；旧曝光分母不与新口径混算 |

指标标签避免 eventId/userId 等高基数；通过带关联 ID 的受控日志/trace 排查。告警附 runbook：查询结果、冻结来源/新资格、续发、隔离重放、预算对账或投影重建。

## 恢复演练边界与验收包

先记录峰值吞吐/热点分布/增长、正常与故障延迟分位、可用性及 RTO/RPO 的目标、估算、实测三列。当前无足够证据填实测值，不能拿配置里的 SLO 当性能报告。

演练目标必须是获授权的隔离库/目录/topic/checkpoint 路径，验证前后源环境没有被覆盖。保留备份 manifest、配置/密钥版本可用性证明、恢复时间线、已恢复数据点、预算/账本差额、预占续办、Outbox/Inbox 补发与投影追平。涉及数据保留/脱敏/删除传播时标记业务依据；没有确认期限不能随意清理财务或幂等历史。

每次切换包包括：通过/未通过矩阵、明确模式/账户/来源范围、业务参数与期初证据、放量观察窗和中止阈值、负责人、停新签发方案、在途义务续办、代码回退兼容和业务补偿方案。没有真实演练不得称“故障可恢复已验收”。
